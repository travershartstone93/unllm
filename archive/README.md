# Archived coding experiments

The [integrated C++ brick pipeline](../experiments/boilerplate/integrated/README.md) is the active coding pilot. This directory holds its predecessors and comparison runs. The [experiment log](../docs/EXPERIMENT_LOG.md) records their outcomes.

| Directory | Earlier approach |
|---|---|
| [boilerplate/two_call](boilerplate/two_call/README.md) | Fixed brick assembly followed by a required model edit |
| [local_interpreter](local_interpreter/README.md) | Standalone local-model request interpretation |
| [interpretation_diagnostics](interpretation_diagnostics/README.md) | Parser, structured extraction, training and model-selection trials |
| [symbolic_distillation](symbolic_distillation/numeric_change/README.md) | Symbolic numeric-change discovery and evaluation |
| [corpus_ablation](corpus_ablation/README.md) | Corpus-based retrieval and synthesis comparisons |
| [algorithm_ir/paired_routes](algorithm_ir/paired_routes/README.md) and [requirements_replay](algorithm_ir/requirements_replay) | English-versus-contract comparisons and saved-requirements replay |

Commit `597b1b0` is the complete pre-cleanup source checkpoint. Use that revision for frozen manifests that refer to the original paths or exact historical source hashes. The USB experiment records are stored separately. The native build can still compile its optional research probes from their archived locations.
