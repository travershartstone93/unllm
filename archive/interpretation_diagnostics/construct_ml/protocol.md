# N15 · Recognizing explicitly requested programming constructs

This isolated native C++ experiment proposes four labels from full English requests. They denote explicitly requested iteration, branching, function definition and console output. An algorithm that could be implemented using a loop does not by itself request a loop. A word in a string, an explanation, a prohibition or a file operation does not request that construct. Either nested order has the same label set. Inputs, body, attachment and program correctness are outside this score.

## Frozen design

Use the 20 single-construct phrases and the training rows for fitting. The lookup baseline matches those phrases on whole-token boundaries. All arms use identical lowercase word tokenization, ignore punctuation as delimiters and abstain on a shared set of explanatory prefixes (explain, describe, what is, what does, tell me whether). Do not silently strip quoted text, interpret negation or use test-time aliases. These are deliberate controls for measuring wrong proposals. Raw requests require no marked spans.

Train four one-versus-rest linear support vector classifiers with OpenCV, binary word unigrams and bigrams, within-token character trigrams and L2-normalized vectors. Fit the vocabulary on training data alone. Use C=1, single-threaded CPU training and positive/negative class weights balancing the two classes. Orient margins using the predicted binary class. The learned fallback runs only when lookup has no hits and the common prefix guard permits proposals. A nonempty set requires every binary decision to clear the same absolute margin. Calibrate on the separate calibration rows at thresholds 0, 0.1, ..., 1.0, or fallback off. Maximize extra exact proposals subject to zero additional wrong proposals; prefer the most conservative setting on ties. Freeze before test. Include an always-off option. Also report the standalone SVM at the chosen operating point as a diagnostic.

Include a second fallback that retrieves the nearest labeled training example using cosine similarity over the same vectors. Give it the same calibration grid and acceptance rule, using cosine as its threshold. Tied nearest examples with different labels cause abstention. This control shares the SVM's training sentences as well as the short lexicon.

Score the hand-authored held split once with each frozen arm. Keep the eight previously observed N14 prompts separate. Count exact nonempty sets, incorrect nonempty sets (including partial predictions), supported abstentions and correct empty-set controls. A proposal confers no permission to emit source. A positive feasibility result requires extra exact proposals on at least two construct types on the held split and zero additional wrong proposals. Record each individual regression even if an aggregate would hide it. Product promotion requires independent end-to-end evidence on a new evaluation.
