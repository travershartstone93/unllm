# Isolated semantic parser feasibility study

Test Stanford SEMPRE's existing discriminative chart parser on whole requests with unknown phrase boundaries. The training set labels only atomic phrases. The target grammar permits a typed numeric or text source, zero or more compatible operations in order, and an output. No English word or whole program appears in grammar productions. Each atom can cover a contiguous span. Use lowercase word and adjacent word-pair features per atom, learned through SEMPRE's log-linear objective with 12 passes, fixed shuffle seed 19, beam 100. Treat punctuation and "and" as available coordination tokens for the vocabulary guard. Normalize case and commas/terminal punctuation consistently in both arms. The order-preserving grammar is a feasibility assumption. It cannot by itself express a clause whose scope reverses surface order.

For each request keep the best score per distinct output, record the runner-up margin and the ungated prediction. Reject unknown tokens and requests when an explicit reject interpretation wins. Calibrate the required score gap on the separate four positive and four stop controls at 0, 0.25, 0.5, 1, 2, 4 or off. Choose the most exact positive predictions with zero incorrect acceptances, favor the higher threshold on ties and off for zero gain. No tuning after scoring transfer. Run the normal stock CLI separately on transfer prompts. Compile/execute proposed stream programs with existing emitters and independent text and number inputs. Score accepted wrong specifications even if the code type-checks. These author-designed development prompts include reused atomic wording and novel compositions. They test the ability to assemble meaning; broader paraphrase transfer and the N16 sealed benchmark remain separate. No project runtime dependency on Java or external model service. No external interpreter receives requests.
