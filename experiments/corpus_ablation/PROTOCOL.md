# Paired source-retrieval development trial

Freeze requests and scoring examples before inspecting corpus expressions. Test one integer-sequence input and one integer or sequence output. The request contains only types and examples. The task names and scoring rows are unavailable to retrieval and search. This is an author-designed development experiment.

Compare the stock native synthesizer, a corpus-free arithmetic proposal adapter, and the same adapter with a curated source index, with a balanced prefix of two downloaded Stack shards, and with a larger prefix of the same shards. Each corpus arm includes the curated index. All adapter arms share their expression universe, generator order, behavioral query, 32-fragment shortlist and outer program sketches. Corpus evidence can only change priorities within equally matching behavioral signatures. Run the unchanged native enumeration as fallback. Count proposals through the native search validator with its normal 100,000-proposal and 120-second limits. Time index construction separately from online retrieval and synthesis. No embeddings or model calls.

Index arithmetic subexpressions, never whole solutions. Accept one distinct identifier, small integer literals and addition, subtraction or multiplication. Drop function names, statements, control flow, collections and file text before retrieval. A retrievable record cannot implement any sequence task in this trial. Generic candidates cover one operation and two-level compositions with a small integer or the input. Rank by singleton example agreement, then observed document frequency, then deterministic structural order. Raw sources are offline only. Count each distinct fragment at most once per deduplicated file. Keep provenance separate from the solver.

Freeze all arm predictions before opening the scoring file. Score emitted Python and sanitized C++ using the existing native validation command. Record unsolved tasks, incorrect accepted programs, construction time, proposal counts and index size. Results apply to this representation and these tasks. The two size increments use nested same-language samples, not new releases of the source datasets.
