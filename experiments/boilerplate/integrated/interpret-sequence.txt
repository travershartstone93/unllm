Translate the English request into one JSON object. Use only the requested deliverable and behavior. No tools or source code.
CLI shape:
{"artifact":{"kind":"cli"},"input_type":"MIME type","roles":[{"id":"r1","text":"purpose of one output","output_type":"MIME type","multiple":false,"content":"whole","requirement":{"operations":[],"runtime":[],"uncovered":[]}}],"responsibilities":[{"id":"a","text":"a reusable responsibility"}]}
One role per independently requested destination, regardless of how many transformations produce it. Put every requested transformation in operations, in order. Each entry is {"outcome":an outcome ID,"parameters":an object}. Use exactly the parameter keys for that chosen outcome, {} if none. Preserve repeated operations and different parameters. Reading the declared input and serializing the output are automatic unless a specific decoding transformation is required.
Use the most specific standard MIME type for each file. content is whole, text, embedded_images, pages, metadata, audio, video, or other. multiple is true for a directory of outputs. The CLI takes input path and destination paths. Plain TSV means headerless tab-delimited records. The first column is 0, the second 1 and the third 2. Use unquoted JSON integers for numeric values. Row positions are one-based. For comparisons use lt, le, eq, ge, gt.
Runtime entries are keys from the supplied runtime dictionary. Put additional constraints or missing operations in uncovered. If no operation matches, leave operations empty and describe the needed behavior in uncovered. For an unresolved necessary choice, return {"clarify":"specific question"}.
