# Answer types: what kind of short answer a question wants, so the answer
# extractor knows which pieces of a passage could answer it. "who sang X"
# wants a person or a band, "when" wants a date, "how many" wants a number.
#
# The question is read lowercased, after chat-speak and rewrites (the same
# text World::answer receives). Three sections:
#
# [patterns]  Lines: pattern ; pattern :: type
#   A pattern must cover the whole question, from its first word to its
#   last. The first line that matches wins, so narrow shapes come first.
#     *     one or more words
#     {N}   a bare name: 1 to 4 words, not starting with the, a or an,
#           none of them a stop word, none ending in "ing" or "ed"
#   Types: person place date year number duration organization title list
#   description none
#     person/organization   either one: a song is sung by a person or a band
#     none                  a yes/no question; the extractor stays out of it
#   Directions, not types:
#     head          look up the head noun in [heads] (how to find it: below)
#     head:T        the same, and T when there is no head noun
#     measure       number, unless the thing measured is an event
#                   (see [events]), then duration
#     list          a list; each item's type is the head noun's type
#
# How the head noun is found: start after the first "what" or "which". Skip
# is, was, are, were, the, a, an. Look at the next 3 words, stopping early at
# "of" or at a stop word; the first one (as its singular, by normalize_word)
# that [heads] knows is the head noun. When that word is "name", skip "of",
# "the", "a", "an" and look again from there ("the name of the river": river).
# A head noun typed in the plural ("which countries") makes the answer a
# list of that type: list:place.
#
# [heads]   Lines: noun ; noun :: type   (singular forms)
# [events]  Lines: noun ; noun ; ...     things that last rather than measure
#   "how long is the flight": flight is an event, so a duration;
#   "how long is the river": a length, so a number.

[patterns]
# yes or no: nothing to extract
is * ; are * ; was * ; were * ; does * ; do * ; did * ; can * ; could * ; has * ; have * ; had * ; will * ; would * ; should * ; shall * :: none
# "who was ada lovelace": tell me about her, not one name
who is {N} ; who was {N} ; who are {N} ; who were {N} :: description
define * ; describe * ; explain * ; tell me about * ; what does * mean ; what is meant by * ; what is the meaning of * :: description
why * ; how does * ; how do * ; how did * ; how is * ; how are * ; how can * ; how to * :: description
# times
what year * ; in what year * ; which year * ; in which year * ; what decade * ; in what decade * ; which decade * :: year
when * ; what date * ; on what date * ; which date * ; what day * ; on what day * ; which day * ; what time * ; at what time * ; since when * ; until when * :: date
# durations; "how long is the river" is a length, so those lines come before the catch-all

how long did * ; how long does * ; how long do * ; how long has * ; how long have * ; how long had * ; how long will * ; how long would * ; how long can * ; how long should * :: duration
how long was * in * ; how long were * in * :: duration
how long is * ; how long are * ; how long was * ; how long were * :: measure
how long * :: duration

# names of things
what is the name of * ; what was the name of * ; what is the name for * ; whats the name of * ; name the * :: head:title
who * named after ; who * named for ; what * named after ; what * named for :: person
what did * invent ; what did * discover ; what did * write ; what does * stand for ; what is * short for :: title
what is * called ; what was * called ; what are * called ; what were * called ; what is * named ; what was * named ; what is * known as ; what was * known as ; what is * also known as ; what was * also known as :: head:title
# who + a verb a band, team or company can do as well as a person
who sang * ; who sings * ; who recorded * ; who performed * ; who released * ; who produced * ; who owns * ; who owned * ; who founded * ; who started * ; who built * ; who makes * ; who made * ; who manufactures * ; who developed * ; who published * ; who publishes * ; who won * ; who wins * ; who beat * ; who defeated * ; who created * ; who designed * ; who sponsors * :: person/organization
who * :: person
# lists
what are the * ; what were the * ; which are the * ; which were the * ; list * ; list the * ; name all * ; name some * :: list
# everything else asked with what or which: the head noun decides
which * ; what * :: head:description
* :: description
